# System Prompt Info

This folder contains information about how Saucepan assembles its system prompt. This information was obtained by using a custom proxy connection to a locally-hosted LLM and inspecting the requests made by Saucepan's backend. It's possible that they do something different for their built-in models, or for the connections to vetted providers.

Currently contains these pages:

- [prompt-format.md](prompt-format.md) describes the system prompt format presently used on Saucepan.
